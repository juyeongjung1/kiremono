01 · WHEN TO USE IT

다음 도전을 고르기 전에, 결과부터

주니어 초반에 수완가를 확인하고 계속 육성할지 정하는 분을 위한 도구입니다.

우마오마카세로 진행하며 다른 일을 할 때

확인하러 돌아오기 전까지 기다리지 않도록

우마오마카세를 켜 두고 다른 일을 하다 보면, 수완가 관련 이벤트가 나왔어도 클래식 1월처럼 시나리오 진행이 멈추는 시점에서야 결과를 확인하게 될 수 있어요. 그러면 다음 도전을 결정하기까지 시간이 더 걸릴 수 있습니다. 중단 시점과 육성 흐름은 시나리오에 따라 달라요.

수완가 알리미는 설정한 이벤트나 자연 획득 능력 문구를 감시 중에 읽었을 때 알려 줍니다. 알림을 보고 결과를 확인한 뒤, 실패했다면 직접 다음 육성을 준비하고 ‘계속 감시 · 실패 후 재도전’으로 감시를 이어 가세요. 획득했다면 수동 획득 기록을 남기거나 자동 기록 여부를 확인하고, 게임에서 직접 본격적인 육성으로 전환하면 됩니다.

수완가를 기다리는 방식을 보조해요.

시나리오와 육성 전략에 따라 이런 활용이 도움이 될 수 있습니다. 수완가 획득 확률이나 최종 능력치를 높여 주는 기능은 아니며, 더 강한 육성 결과를 보장하지 않습니다. 이벤트 알림 뒤에는 OCR가 멈추므로 실제 결과 확인과 수동 획득 기록을 잊지 마세요.

한국 서버 이용 시 참고

한국판은 현재 우마오마카세 육성이 없어, 위와 같은 방치형 엄선 방식은 아직 이용할 수 없습니다. 한국어 화면 감지와 수동 기록 기능과는 별개의 안내입니다.

화면 위쪽에 고정

시작·종료는 상단, 통계는 오른쪽 위

  • 육성 감시 시작과 감시 종료는 설정 화면을 아래로 내려도 상단에 남습니다.
  • 오른쪽 위 통계 보기를 누르면 별도 통계 화면으로 이동합니다.

02 · QUICK START

첫 감시를 시작하는 순서

처음 한 번은 짧게 시험해 보고, 본격적인 육성에 사용해 주세요.

  1. 기기에 맞는 APK 설치

    별도로 제공받은 APK 중 64비트 ARM 기기는 ARM64, 32비트 ARM 기기는 ARMv7을 선택합니다. Android 8.0 이상이 필요해요. 일반적인 최신 ARM 기기에는 ARM64를 우선 확인하세요.

    설치 파일의 출처와 기기 호환성을 확인하세요.

  2. 알림을 허용하고 소리·진동 확인

    앱이 요청하는 알림 권한을 허용합니다. 알림 방식을 고른 뒤 선택한 알림 방식 테스트 (5초)로 실제 반응을 확인하세요.

    알림이 꺼져 있다면 알림 설정 열기에서 확인할 수 있습니다.

  3. 서버 → 캐릭터 → 의상 선택

    게임 서버를 맞추고, 캐릭터 이름을 검색해 육성 캐릭터와 의상을 선택하세요. 이벤트 제목도 감지하려면 선택한 육성 이벤트도 감지를 켜고 감지 대상 목록을 확인합니다.

    원하는 이벤트가 없다면 게임에 표시되는 원문을 한 줄에 하나씩 직접 입력할 수 있어요. 서버·캐릭터·의상은 감시를 시작하기 전에 정합니다.

  4. 필요하면 화면 범위와 인식을 시험

    분할 화면을 쓴다면 작은 창·분할 화면 모드에서 읽을 영역을 설정합니다. 이미지로 문자 인식 테스트에 게임 스크린샷을 선택하면 현재 서버와 설정의 인식을 확인할 수 있어요.

    이미지 테스트는 통계에 포함되지 않습니다. 실시간 감시가 잘 된다는 보장은 아니므로 게임 화면에서도 확인해 주세요.

  5. 상단 ‘육성 감시 시작’ → 화면 공유 허용

    육성 감시 시작을 누르고 Android 화면 공유를 허용하세요. Android 14 이상에서 선택지가 보이면 우마무스메 앱만 공유하는 방식을 권장합니다. 전체 화면의 특정 영역을 지정한 경우에는 전체 화면 공유가 사용됩니다.

    화면 공유가 실제 준비되어야 시도 1회가 시작됩니다. 공유를 취소하거나 초기 시작에 실패하면 시도가 추가되지 않아요.

  6. 게임으로 돌아가 화면을 켜 두기

    상태 안내에서 화면 수신과 문자 인식이 진행되는지 확인하고 게임을 플레이하세요. 감지 알림이 오면 게임을 직접 확인한 뒤 아래 상황별 방법으로 결과를 기록합니다.

    앱 설정 화면을 떠나도 감시는 계속되지만, 화면 잠금이나 공유 종료 시에는 감시가 중지됩니다.

업데이트할 때 기존 앱을 먼저 삭제하지 마세요.

설정과 기록을 유지하려면 새 APK를 기존 앱 위에 덮어 설치하세요. 설치가 되지 않으면 앱이나 데이터를 지우지 말고 먼저 호환성을 확인해 주세요.

03 · THREE SITUATIONS

알림 뒤에는 무엇을 누를까요?

‘재도전’과 ‘잠시 중지’는 기록에 남는 결과가 다릅니다.

A

이벤트를 못 보고 육성을 포기했어요

OCR 감시가 켜진 동안 종료 확인 문구를 읽으면 현재 육성을 실패 1회로 기록하고 감시를 끝냅니다. 다음 육성은 앱에서 직접 시작해 주세요.

  • 일본 서버: 「育成をあきらめて終了します」를 감지합니다.
  • 한국 서버: 「육성을 포기하고 종료합니다」를 기본 문구로 사용합니다. 게임 화면과 다르면 문구를 수정하거나 비워서 감지를 끌 수 있습니다.

문구를 못 읽었거나 감지를 꺼 둔 경우에는 실패가 자동 기록되지 않습니다. 같은 대상으로 다음 감시를 시작할 때 재도전 · 이전 육성 실패, 새 시도 +1을 선택하면 이전 육성을 실패로 처리하고 새 시도를 시작합니다.

유효한 종료 문구 감지→실패 +1 · 감시 종료→다음 육성 직접 시작
B

이벤트는 떴지만 수완가를 못 얻었어요

실제로 이번 육성을 실패 처리하고 새로 도전하려면 앱의 계속 감시 · 실패 후 재도전을 누르세요. 알림창에서는 계속 감시 · 재도전, 제어 팝업에서는 실패 후 재도전입니다.

누르는 즉시 현재 육성을 실패로 기록하고, 10초 뒤 새 시도와 재도전 1회를 추가하며 감지를 재개합니다. 게임에서 다음 육성을 준비하고 시작하는 조작은 직접 해야 합니다.

10초 대기 중에 중지하면?

이미 기록한 현재 육성의 실패는 남지만, 새 시도와 재도전은 추가되지 않습니다. ‘계속 감시’는 같은 육성을 단순히 이어 읽는 버튼이 아니에요.

C

수완가를 획득했어요

수동 기록: 게임에서 획득을 확인했다면 앱의 획득 기록 · 알림과 감시 중지 또는 알림창·제어 팝업의 수완가 획득을 누릅니다. 획득 1회를 기록하고 알림과 감시를 중지해요.

자동 기록: OCR 감시가 켜져 있을 때 한국판의 「수완가」 또는 일본판의 「切れ者」 능력 문구가 감지되면 획득을 자동 기록하고 화면 공유를 끝냅니다. 같은 육성의 수동·자동 기록이 겹쳐도 획득은 한 번만 셉니다.

이벤트 알림 뒤에는 수동 기록이 중요해요.

이벤트를 감지하면 OCR가 멈춥니다. 화면 공유는 유지되어도 글자를 계속 읽지는 않으므로, 그 뒤 획득했다면 획득 기록 버튼을 눌러 주세요. 능력 설명 화면을 획득으로 오인할 수도 있으니 자동 기록 후에도 게임에서 실제 결과를 확인하세요.

잠깐 쉬거나 같은 육성을 계속할 때

일반 ‘감시 종료’는 성공도 실패도 아니에요

감시 종료는 감시와 알림을 멈춥니다. 같은 서버·캐릭터·의상으로 다시 시작할 때 중지한 육성 이어 보기 · 시도 수 유지를 선택하면 기존 시도에 이어서 감시할 수 있어요. Android 화면 공유는 다시 허용해야 합니다.

‘새 육성 시작 · 이전 기록 보존’을 고르면 기존 기록을 남긴 채 새 시도를 만듭니다. 이전 육성을 자동으로 실패 처리하는 선택은 아닙니다.

종료 문구의 중복·직후 오기록을 줄이는 보호 규칙

알림이 시작된 뒤 30초 이내(정확히 30초 포함)에는 종료 문구를 실패로 세지 않습니다. 같은 종료 화면이 계속 보이면 반복 실패를 만들지 않으며, 보호 시간에 본 문구도 사라진 것이 확인되어야 다시 감지 대상으로 삼습니다. 30초가 지났다는 이유만으로 같은 창을 뒤늦게 실패 처리하지는 않아요.

04 · YOUR RECORDS

숫자는 이렇게 쌓여요

오른쪽 위 ‘통계 보기’에서 서버별 합계, 날짜별, 캐릭터·의상별 기록을 볼 수 있습니다.

통계 항목과 기록 기준
항목언제 올라가나요?
시도새 육성의 화면 공유가 준비되면 +1. 재도전으로 시작한 새 육성도 포함합니다. 중지한 육성을 이어 보면 늘지 않아요.
재도전이전 실패 후 새 시도가 실제 시작되면 +1. 시도에 포함되는 숫자이므로 시도와 더해 총 육성 수로 계산하지 않습니다.
실패유효한 종료 문구를 감지하거나 실패 후 재도전을 선택했을 때 기록합니다. 일반 중지나 앱 강제 종료만으로는 실패가 기록되지 않습니다.
이벤트등록한 이벤트 제목을 감지했을 때 기록합니다. 같은 육성의 같은 이벤트는 한 번만 세며, 서로 다른 이벤트는 각각 기록할 수 있습니다.
획득수동 획득 버튼 또는 OCR 능력 문구 감지로 기록합니다. 한 육성당 최대 1회이며 이벤트 감지만으로는 올라가지 않아요.
획득률의 분모를 확인하세요
획득한 육성 ÷ 시작한 육성 × 100

진행 중·실패·결과를 기록하지 않은 육성도 모두 분모에 포함됩니다. 시도가 0회라면 ‘—’로 표시합니다.

예시: 시도 10회 중 획득 1회라면 획득률은 10%입니다. 이 숫자는 이 앱으로 기록한 개인 결과이며, 게임의 실제 획득 확률을 보증하거나 추정해 주는 값은 아닙니다.

날짜는 육성을 시작한 날 기준

시작 당시 서버·캐릭터·의상과 기기의 현지 날짜·시간대를 기준으로 기록합니다. 자정을 넘기거나 기기 시간대를 바꿔도 이미 시작한 육성의 일별 기록은 다른 날짜로 이동하지 않아요.

예를 들어 밤 11시 50분에 시작해 다음 날 획득했다면, 처음 시작한 날짜의 기록에 포함됩니다. 설치 전 육성 이력을 게임에서 가져오는 기능은 없습니다.

06 · MAKE IT FIT

내 화면과 알림에 맞추기

처음에는 단순한 설정으로 시작하고, 필요한 부분만 조절하세요.

소리 또는 진동
소리 모드 (소리 + 진동)와 진동 모드 (소리 없음) 중 선택합니다. 실제 감지 알림의 소리·진동은 최대 20초이며, 기기 음량·무음·알림 설정의 영향을 받습니다. 소리가 끝나도 이벤트 감지 뒤의 OCR가 자동 재개되지는 않아요.
선택 사항: 게임 위 제어 팝업
감지 시 제어 팝업 표시를 쓰려면 다른 앱 위에 표시 권한 설정에서 Android 권한을 켜야 합니다. 팝업 없이 알림창으로도 조작할 수 있습니다. 접근성 권한은 사용하지 않아요.
작은 창·분할 화면
작은 창·분할 화면 모드에서 공유한 앱 전체 (권장) 또는 전체 화면의 위·아래·왼쪽·오른쪽·직접 지정 영역을 선택합니다. 직접 지정 범위는 왼쪽 위 0%, 오른쪽 아래 100%를 기준으로 합니다.
눌려 보이는 글자 보정
가로·세로 보정은 글자가 한쪽 방향으로 눌려 보일 때 조절합니다. 모든 화면에서 배율을 높이는 것이 더 정확한 것은 아니에요. 영역과 보정을 바꾼 뒤에는 이미지 테스트로 먼저 확인하세요.
한국판 종료 문구 편집
실제 게임의 육성 포기 확인 문장을 그대로 입력하세요. 공백을 제외하고 8자 이상, 전체 256자 이하이며, 비우면 종료 문구 감지를 끕니다. 일반 대사나 흔한 문구를 넣으면 실패가 잘못 기록될 수 있습니다.
분할 위치를 바꾸거나 화면을 회전했다면 다시 확인하세요.

글자가 작으면 누락될 수 있고, 화면 비율이 바뀌면 감지가 중지될 수 있습니다. 분할 화면과 앱 하나만 공유하는 동작은 기기·Android 버전에 따라 달라 실제 기기에서 확인이 필요합니다.

07 · LOCAL & PRIVATE

화면은 기기 안에서, 기록도 기기에

게임 계정이나 비밀번호를 앱에 입력할 필요가 없습니다.

저장하는 것

선택한 설정과 육성 시도·이벤트·획득 등의 통계를 기기에 저장합니다. 앱 자체의 인터넷 권한이 없어 서버로 통계를 보내지 않습니다.

저장하지 않는 것

화면 이미지와 읽은 문장은 저장하거나 전송하지 않습니다. 이미지 테스트용으로 고른 파일도 앱이 따로 저장하지 않아요.

화면 공유 범위를 직접 확인해 주세요.

Android 화면 공유는 선택한 앱 또는 전체 화면의 내용을 앱이 읽을 수 있게 합니다. 가능하면 게임 앱만 공유하고, 전체 화면 공유 중에는 개인정보가 있는 앱을 열기 전에 감시를 중지하세요. 사용이 끝나면 감시와 공유도 종료해 주세요.

앱 삭제·데이터 삭제 전에 기록을 확인하세요.

기록은 기기에 보관되며 자동 백업·동기화는 지원하지 않습니다. 앱을 삭제하거나 데이터를 지우면 기록을 잃을 수 있어요. 기록 오류가 나타났을 때도 삭제하거나 초기화하지 말고 현재 설치와 데이터를 보존하세요.

08 · FAQ & TROUBLESHOOTING

잘 안 될 때 먼저 확인할 것

질문을 누르면 답변이 펼쳐집니다.

이벤트 알림은 왔는데 획득 수가 그대로예요.
정상일 수 있습니다. 이벤트 제목 감지는 이벤트 기록만 올립니다. 이벤트 알림 뒤에는 OCR가 멈추므로, 이후 실제 획득했다면 ‘획득 기록 · 알림과 감시 중지’ 또는 알림창의 ‘수완가 획득’을 눌러 주세요.
알림이 오지 않거나 소리가 안 나요.
서버·캐릭터·의상, 이벤트 감지 체크와 대상 목록, 화면 공유 대상 및 읽을 영역을 먼저 확인하세요. 앱의 화면 수신·문자 인식 상태와 Android 알림 허용, 음량·무음 설정도 점검합니다. ‘선택한 알림 방식 테스트 (5초)’와 이미지 테스트를 해 보세요. 잠깐 나타나는 글자나 작은 글씨는 놓칠 수 있고, 기기의 배터리 관리도 동작에 영향을 줄 수 있습니다.
수완가 설명만 봤는데 획득으로 기록됐어요.
OCR는 화면 글자를 읽을 뿐 실제 게임 상태를 확인하는 기능이 아닙니다. 능력 설명이나 유사 문구를 획득으로 오인할 수 있습니다. 모든 설명 화면을 구별할 수는 없어요. 능력 설명 등을 열기 전에는 감시를 중지하고, 자동 기록도 게임 결과와 대조해 주세요. 현재 앱에는 잘못된 기록을 개별 수정·삭제하는 화면이 없습니다.
한국 서버인데 이벤트가 목록에 없어요.
자료에서 확인하지 못한 항목은 자동 이벤트 감지 목록에서 제외되어 있습니다. 미출시라고 단정한 것은 아닙니다. 정확한 한국어 이벤트 제목을 알고 있다면 직접 입력할 수 있으며, 능력 문구 감지와 수동 획득 기록은 계속 사용할 수 있습니다.
그냥 멈췄는데 실패 기록이 안 늘었어요.
일반 ‘감시 종료’는 결과 기록 없이 중지하는 기능입니다. 같은 육성을 계속하려면 ‘중지한 육성 이어 보기 · 시도 수 유지’를, 이전 육성을 실패 처리하고 다시 시작하려면 ‘재도전 · 이전 육성 실패, 새 시도 +1’을 선택하세요. ‘계속 감시 · 실패 후 재도전’ 역시 실패 후 새 시도를 뜻합니다.
기록을 읽을 수 없다는 오류가 나요.
앱을 삭제하거나 데이터를 지우지 마세요. 앱은 손상된 기록을 자동으로 초기화하지 않습니다. 오류 문구와 발생 상황을 남기고 현재 데이터를 보존한 상태로 원인을 확인해야 합니다.
처음 사용할 때 무엇을 확인하면 좋을까요?
실제 게임 화면 인식과 기기별 알림·소리·진동·분할 화면 동작은 아직 검증되지 않은 시험 버전입니다. 처음에는 짧은 육성 구간에서 화면이 읽히는지, 알림이 오는지, 기록이 실제 결과와 맞는지 직접 확인해 주세요.
사용하면 획득 확률이나 계정 안전이 보장되나요?
획득 확률을 바꾸는 앱이 아니며, 인식 정확도·성공률·계정 제재 여부를 보장하지 않습니다. Cygames·카카오게임즈와 제휴하거나 공인받은 앱이 아닌 비공식 도구입니다. 사용 전 게임의 최신 이용약관과 운영정책을 직접 확인해 주세요.
